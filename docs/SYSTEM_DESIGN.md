# 系統設計文件

## 功能與畫面

### 主地圖

- 地圖延伸至螢幕邊緣；搜尋框、標記操作、署名避開系統列可點擊區域。
- 頂端搜尋框以放大鏡或鍵盤「搜尋」送出查詢；點結果移動地圖，或直接新增為個人地標。查詢欄右側的地標按鈕開啟「我的地標」。
- 右下角圖示按鈕分別用於分享目前位置及按需定位；不顯示地圖放大縮小按鈕，使用雙指手勢縮放。
- 首次使用時顯示可關閉的長按提示；OpenStreetMap 與 Nominatim 署名保持可見。
- 個人地標（珊瑚紅）、搜尋結果（紫色）、目前位置（藍色）使用不同標記。點個人地標先顯示資訊，再選擇編輯。

### 我的地標

- 全螢幕清單，上方為返回圖示及本機搜尋欄；名稱下方顯示非空白備註。
- 點項目返回地圖並移至該地標；點右側編輯圖示開啟編輯表單，避免兩種操作互相觸發。
- 下方按鈕由左至右為「匯出、匯入、關閉」。匯入後清單透過 Room Flow 更新。

## 地標資料模型

`Place`（Room 資料表 `places`）：

| 欄位 | 型別 | 規則 |
| --- | --- | --- |
| `id` | String | UUID、主鍵；匯入時重新產生 |
| `name` | String | 新增時必填，上限 100 字元；匯入缺少名稱時使用預設值 |
| `note` | String | 選填，上限 2,000 字元 |
| `latitude` | Double | 緯度；與經度共同建立唯一索引 |
| `longitude` | Double | 經度；與緯度共同建立唯一索引 |

匯入時接受 `FeatureCollection` 中合法的 `Point`，檢查緯度在 -90 至 90、經度在 -180 至 180，略過不合法的 feature 並計數；整體格式錯誤時顯示失敗。資料庫的唯一索引以座標的精確值判斷重複（不是距離容差或同名判斷）。匯出時只包含 `Point` 幾何與名稱、備註；GeoJSON 坐標順序為**經度、緯度**。

## 狀態與錯誤處理

- 初次開啟使用世界地圖視角；之後還原最後中心點與縮放，無效儲存值會退回預設值。
- 允許粗略或精確定位後執行單次定位，超時約 15 秒；未取得位置、未開啟定位或拒絕權限時提示使用者。
- 分享目前位置時重新定位，取得結果後以裝置當地時間、六位小數經緯度及 Google 地圖度分秒網址組成三行文字，再交由系統分享選單。度分秒四捨五入至 0.1 秒，南緯／西經分別使用 S／W；若無法定位則不分享。
- 線上搜尋只在明確送出時發送，最多回傳五筆；空白、無網路、查無結果及服務錯誤有個別處理。
- 匯入檔案上限 5 MB；相同座標直接略過，不覆寫原有地標。修改與刪除由使用者於編輯介面操作，刪除另有確認視窗。

## 後續擴充界線

目前只保證**個人地標**離線可用。地圖圖磚的暫存不可視為離線地圖；若未來加入離線地圖，須先挑選允許離線使用的資料來源，不能從 OSM 公用圖磚伺服器預先批次下載。
