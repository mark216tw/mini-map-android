# mini地圖使用指南

## 安裝與基本操作

使用 Android 8.0（API 26）以上裝置安裝 APK，並保持網路連線以載入地圖。地圖可用單指拖曳、雙指縮放；重新開啟 APP 會還原上次的地圖位置與縮放。首次開啟時會提示「長按地圖新增地標」，點「知道了」或實際長按後便不再顯示。

按右下角定位圖示時，APP 才會要求定位權限。允許後，地圖移往目前位置；如沒有定位訊號、權限被拒或手機未開啟定位，可繼續瀏覽地圖與使用個人地標。

右下角的**分享圖示**會重新取得目前位置（不是地圖中心或上一次定位點），必要時先要求定位權限。成功後開啟 Android 系統分享選單，分享文字依序包含手機當地時間、六位小數的經緯度，以及 Google 地圖度分秒網址，例如：

```text
2026/09/27 11:44:11
22.985160°, 120.196722°
https://www.google.com.tw/maps/place/22°59'06.6"N+120°11'48.2"E
```

定位失敗或拒絕權限時不會分享先前的位置。分享目的地由使用者在系統分享選單中選擇。

## 查詢地點

於頂端橢圓搜尋框輸入地名，點放大鏡或按鍵盤「搜尋」。點結果名稱會移動地圖，點「加入地標」會預填名稱與座標並開啟新增表單；搜尋標記也可點擊新增。線上查詢需要網路，空白查詢不會送出。搜尋結果標記為紫色，個人地標為珊瑚紅，目前位置為藍色。

## 個人地標

- **新增**：長按地圖或由線上搜尋結果選取位置，輸入名稱（必填，可加備註）後儲存。相同座標僅能有一個個人地標。
- **查看**：點地圖上的珊瑚紅標記，先查看名稱、備註、經緯度；按「編輯」才進入編輯表單。
- **列表與本機搜尋**：點**查詢欄位右側**的地標圖示開啟「我的地標」。可用名稱或備註搜尋；此搜尋不需網路。點列表項目可定位，點最右側編輯圖示可修改名稱、備註或刪除。
- **返回**：點左上角向左箭頭、頁面底部「關閉」，或使用手機返回操作。

個人地標儲存在本機 Room 資料庫，APP 不建立帳號，也不提供自行上傳地標的雲端同步；Android 系統備份行為依裝置設定而定。重新安裝 APP 或清除 APP 資料可能移除本機地標，建議定期匯出備份。

## GeoJSON 備份

於「我的地標」頁面底部點「匯出」或「匯入」，使用 Android 系統的檔案選取器存取檔案，不需額外儲存權限。匯出檔預設為 `mini-map-places.geojson`。

匯入支援 GeoJSON `FeatureCollection` 中的 `Point` 地物；座標必須依規格為 `[經度, 緯度]`。名稱及備註分別使用 `properties.name`、`properties.note`；無名稱時使用「未命名地標」。匯入檔案上限為 **5 MB**。座標與現有地標完全相同時跳過，完成後顯示新增、重複與無效筆數。匯入不會覆寫既有地標。

## 網路與離線範圍

地圖圖磚、線上地名查詢需要網路；離線時仍可查看、搜尋、編輯、匯入及匯出已儲存的個人地標。已瀏覽圖磚可能存在暫存，但不保證離線可用。APP **不提供離線地圖下載**。GPS 定位可能在沒有網路時運作，但取得位置的速度與精度依裝置及環境而異。
